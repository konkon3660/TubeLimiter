# TubeLimiter

> 유튜브 과소비를 막고 건강한 디지털 시청 습관을 만들어주는 브라우저 확장 프로그램입니다.

TubeLimiter는 사용자가 설정한 일일 시청 시간을 추적하고, 제한 시간이 되면 YouTube 접근을 차단하여 사용자가 자신의 시간을 더 효율적으로 관리할 수 있도록 돕습니다.

---

## ✨ 주요 기능

- **📈 사용 시간 추적 및 시각화**:
  - 일일 YouTube 사용 시간을 분 단위로 기록합니다.
  - **통계 페이지**에서 지난 7일 또는 30일간의 사용 기록을 막대그래프로 시각화하여 제공합니다.
  - 총 사용 시간과 일평균 사용 시간을 요약하여 보여줍니다.

- **⏱️ 유연한 시청 시간 제한**:
  - **일일 시청 시간 제한**을 분 단위로 설정할 수 있습니다.
  - 제한 시간을 초과하면 YouTube 페이지에 차단 오버레이가 표시됩니다.
  - **요일별**로 다른 시간 제한을 설정하는 고급 기능을 지원합니다. (예: 주중 30분, 주말 90분)

- **🆘 긴급 시청 기능**:
  - 제한 시간을 모두 사용했더라도, 정말 필요할 때를 위해 **긴급 시청**을 요청할 수 있습니다.
  - 긴급 시청은 1회 요청 시 5분간 허용됩니다.
  - 긴급 시청 가능 횟수는 **일별, 주별, 월별, 또는 요일별**로 재설정되도록 설정할 수 있습니다.

- **🧘 집중 모드**:
  - 특정 시간 동안 YouTube로부터 완전히 벗어나고 싶을 때 **집중 모드**를 활성화할 수 있습니다.
  - 설정된 시간 동안은 시청 제한 시간과 관계없이 YouTube가 즉시 차단됩니다.

- **⚙️ 다양한 사용자 설정**:
  - **YouTube Shorts 항상 차단**: Shorts 피드를 보지 않도록 설정할 수 있습니다.
  - **URL 화이트리스트**: 특정 채널이나 동영상 URL을 화이트리스트에 추가하여 제한 규칙에서 제외할 수 있습니다.
  - **다크 모드**: 눈의 피로를 덜어주는 다크 모드 테마를 지원합니다.

- **팝업 UI**:
  - 브라우저 툴바 아이콘을 클릭하여 오늘의 사용량, 남은 시간, 남은 긴급 시청 횟수 등을 빠르게 확인할 수 있습니다.
  - 팝업에서 바로 집중 모드를 시작하거나 긴급 시청을 요청할 수 있습니다.

## 🛠️ 기술 스택

- **Frontend**: HTML, CSS, JavaScript (ES Modules)
- **Charts**: [Chart.js](https://www.chartjs.org/)
- **Platform**: Chrome WebExtensions API (Manifest V3)

## 🚀 설치 및 사용법

### 개발용으로 설치하기

1.  이 저장소를 로컬 컴퓨터에 복제(clone)하거나 다운로드합니다.
2.  Chrome 브라우저에서 `chrome://extensions` 주소로 이동합니다.
3.  오른쪽 상단에서 **'개발자 모드'**를 활성화합니다.
4.  **'압축 해제된 확장 프로그램을 로드합니다'** 버튼을 클릭합니다.
5.  다운로드한 프로젝트 폴더(`TubeLimiter`)를 선택합니다.
6.  이제 브라우저 툴바에 TubeLimiter 아이콘이 추가됩니다.

### 사용법

1.  툴바의 TubeLimiter 아이콘을 클릭하여 팝업을 엽니다.
2.  팝업 하단의 **'옵션'** 버튼을 클릭하여 설정 페이지로 이동합니다.
3.  '시간/횟수 설정' 탭에서 일일 시청 제한 시간과 긴급 시청 횟수 등을 원하는 대로 설정하고 저장합니다.
4.  YouTube를 시청하면 시간이 자동으로 기록되며, 팝업에서 남은 시간을 확인할 수 있습니다.
5.  **'통계 보기'** 버튼을 눌러 자신의 시청 습관을 분석해 보세요.

## 📂 프로젝트 구조

```
TubeLimiter/
├── 📄 manifest.json            # 확장 프로그램의 설정 파일 (이름, 버전, 권한 등)
├── 📄 background.js            # 사용 시간 추적, 차단 로직 등 핵심 백그라운드 스크립트
├── 📄 content.js               # YouTube 페이지에 직접 삽입되어 차단 화면을 표시하는 스크립트
│
├── 🖼️ popup.html               # 툴바 아이콘 클릭 시 나타나는 팝업 UI
├── ⚙️ popup.js                 # 팝업의 데이터 표시 및 상호작용 로직
│
├── 🖼️ options.html             # 설정 페이지 UI
├── ⚙️ options.js               # 설정 페이지의 모든 기능(저장, 불러오기 등) 로직
│
├── 🖼️ usage_stats.html         # 통계 페이지 UI
├── ⚙️ usage_stats.js           # Chart.js를 이용해 통계 데이터를 그리는 로직
│
├── 📁 assets/                  # 아이콘, CSS, 외부 라이브러리(Chart.js) 등 정적 파일
│   ├── 🎨 common.css
│   └── 🎨 popup_animations.css
│
└── 📁 utils/                   # 공통 유틸리티 함수
    ├── 📦 storage.js            # chrome.storage API를 쉽게 사용하기 위한 래퍼
    └── 📦 time.js                # 날짜/시간 관련 헬퍼 함수
```
